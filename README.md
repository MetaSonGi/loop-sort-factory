# 컨베이어 분류 퍼즐 — Loop Sort Factory

2026년 대세 **Sort(분류) 메카닉**의 웹 아케이드 게임.
컨베이어 위로 흘러오는 제품을 터치하고 같은 색 분류함에 넣어라!

🌐 **바로 실행:** https://metasongi.github.io/loop-sort-factory/

## 게임 방법

1. ▶ 시작하기를 누르면 제품이 컨베이어 위로 흘러옵니다
2. 제품을 터치해 선택 → 같은 색 분류함을 터치
3. 틀리거나 놓치면 목숨 -1 (❤×3)
4. 10개 분류마다 레벨업 → 더 빨라집니다
5. 연속 정답 콤보로 점수 배율 상승 (최대 x8)

## 기술

- Vanilla JS + DOM/CSS 애니메이션
- requestAnimationFrame 게임 루프
- 최고 기록 localStorage 저장
- 모바일 터치 대응
